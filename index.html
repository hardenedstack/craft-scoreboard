How we test

Method

A result covers only the version and the date shown. A newer version can behave differently.

Score

Same jobs, rules written first

Each job is graded PASS 1, PARTIAL 0.5 or FAIL 0. The grading rules for every job are written down before the first app runs it, and both apps get the same jobs and the same files.

Pass 1Partial 0.5Fail 0
Connections

Counted per program

Connections are network connections made by the app's own processes during the test, captured on the lab PC (packet capture plus the operating system's per-program connection log).

Paid apps run with default settings and the account they ask for. Web apps are measured in the browser session we used for the jobs.

Scope

One version, one date

Developers ship fixes, and Microsoft and Adobe change their services. A result says what we measured on that version, on that date, on our lab PC. It is not a verdict on any company.

Each result links to the video that shows the test.
